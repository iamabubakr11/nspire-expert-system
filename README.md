# Nspire Dev — Expert System

Учебный прототип экспертной системы для кейс-задачи № 3. По ответам клиента рекомендует лендинг, корпоративный сайт, сайт-каталог, интернет-магазин или веб-приложение. Решение принимает **реальная оболочка CLIPS** через библиотеку CLIPSPy, не набор if/else в браузере.

## Что нужно

- Windows 10/11, macOS или Linux
- **Python 3.11 или 3.12 (64-bit)** — рекомендуемый вариант для первой установки
- VS Code (необязательно, но удобно)
- Интернет для первого `pip install` и загрузки Google Fonts; шрифты имеют локальные запасные варианты

## Запуск в VS Code на Windows

1. Распакуй ZIP, открой папку `nspire-expert-system` в **File → Open Folder** в VS Code.
2. Установи Python с сайта https://www.python.org/downloads/ (на Windows включи **Add Python to PATH**). Перезапусти VS Code после установки.
3. Открой **Terminal → New Terminal**, вставь команды **по очереди**:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

4. Открой в браузере: **http://127.0.0.1:5000**.
5. Чтобы остановить сервер, нажми **Ctrl+C** в терминале.

> Если `py` не распознаётся, попробуй `python -m venv .venv`. Остальные две команды остаются прежними. Отдельно активировать виртуальное окружение не нужно.

## Запуск на macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Открой http://127.0.0.1:5000.

## Автоматические тесты

Windows:
```powershell
.\.venv\Scripts\python.exe -m pytest -q
```
macOS / Linux:
```bash
.venv/bin/python -m pytest -q
```

Тесты проверяют пять основных кейсов, **все 12 сочетаний ответов**, некорректные входные данные и HTTP API. Результат успешного тестирования будет показан в терминале.

## Как устроен вывод

`HTML-форма → POST /api/recommend → Flask → CLIPSPy → CLIPS rules.clp → рекомендация + объяснение → интерфейс`.

Ответы принимаются в формате:

```json
{"goal":"products","payment":"yes","accounts":"no"}
```

- `goal`: `products`, `company` или `campaign`;
- `payment`: `yes` / `no`;
- `accounts`: `yes` / `no`.

Сначала проверяется потребность в личных кабинетах (самый высокий приоритет); если кабинеты не нужны, цель и онлайн-оплата определяют тип сайта. Каждая консультация использует отдельное CLIPS-окружение. Вывод содержит идентификатор сработавшего правила и объяснение на русском.

## Что сдать преподавателю

1. ZIP с исходниками (этот проект).
2. 3–5 скриншотов работающего интерфейса и рекомендаций.
3. Скриншот терминала с успешными тестами.
4. Отчёт из `docs/CASE_3_REPORT.md` (1,5–2 страницы при обычном форматировании; подгони форматирование под методичку).

**Важно:** до реального запуска в твоей среде не следует писать в отчёте, что тесты успешно пройдены. Сделай запуск и заполни результаты. Папку `.venv` в архив для преподавателя добавлять не надо.

## Ограничения

Это учебная модель с 3 входными параметрами и 5 типами решений. Она не рассчитывает стоимость и сроки и не заменяет техническое обследование проекта. Обработка новых задач потребует расширения правил и анкеты. Сервер Flask запускается локально и не предназначен для публичного production-хостинга.
