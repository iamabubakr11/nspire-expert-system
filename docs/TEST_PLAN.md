# План проверки экспертной системы

## Функциональные сценарии

| ID | Цель | Онлайн-оплата | Кабинеты | Ожидается | Правило |
|---|---|---|---|---|---|
| T01 | Продажа товаров | Да | Нет | Интернет-магазин | R02 |
| T02 | Продажа товаров | Нет | Нет | Сайт-каталог | R03 |
| T03 | Информация о компании | Нет | Нет | Корпоративный сайт | R04 |

Дополнительно автотест `test_all_twelve_combinations_choose_once` проверяет все 12 комбинаций; тесты ошибки проверяют валидацию ввода. Реальный результат фиксируется **после запуска тестов**, а не заранее.

## Как снять скриншоты для кейса

1. Запусти Flask, открой `http://127.0.0.1:5000` и сделай скриншот стартового экрана.
2. Выбери «Продажа товаров» + «Да, нужна» + «Нет». Нажми «Получить рекомендацию», сохрани скриншот интернет-магазина с объяснением и правилом R02.
3. Выбери «О компании» + «Нет» + «Нет». Сохрани результат «Корпоративный сайт» (R04).
4. Выбери «Одна услуга» + «Нет» + «Нет». Сохрани результат «Лендинг» (R05).
5. В VS Code открой `expert/rules.clp` и сними скриншот правил.
6. Запусти `python -m pytest -q` внутри `.venv` и сохрани результат тестирования в терминале.

В Word добавь подписи «Рисунок 1 — Интерфейс экспертной системы», «Рисунок 2 — Результат логического вывода CLIPS», «Рисунок 3 — База знаний», «Рисунок 4 — Тестирование».
